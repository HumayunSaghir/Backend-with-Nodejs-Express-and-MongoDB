# HTTP Methods in Node.js

## Key Topics Covered

- Introduction to HTTP methods.
- **GET:** Retrieving data from the server.
- **POST:** Sending data to the server.
- **PUT:** Replacing existing resources on the server.
- **PATCH:** Partially updating existing resources.
- **DELETE:** Removing resources from the server.
- Using Chrome DevTools → Network tab to inspect HTTP methods.
- Understanding why login requests should use the POST method.
- Identifying request methods on the server using `req.method`.
- Handling and logging HTTP methods in Node.js.
